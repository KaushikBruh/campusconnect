ABOUT THE PROJECT

College life, connected.

CampusConnect is an academic website project that brings college events, student communities and campus announcements into one easy-to-use interface.

01 · DISCOVER

Find events

Search and filter workshops, cultural programmes, sports activities and career events.

02 · PARTICIPATE

Join communities

Explore student clubs and make it easier to take part in campus life.

03 · ORGANIZE

Admin workspace

Authorized administrators can publish event information and announcements.

Project technologies

HTML5, CSS3, JavaScript and Supabase (authentication and database, when configured). GitHub Pages is used for static website hosting.

Academic note: The deployed version should be tested after the project owner configures the backend. Do not enter real student information until authentication, database policies and institutional permissions have been reviewed.
